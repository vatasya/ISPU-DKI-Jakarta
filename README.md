# ISPU-DKI-Jakarta Tahun 2022

Project ini merupakan eksplorasi dan visualisasi data kualitas udara di DKI Jakarta Tahun 2022 menggunakan python. Analisis ini dilakukan untuk memahami karakteristik data, distribusi kualitas uadara, hubungan antara parameter polutan, serta variasi berdasarkan lokasi dan waktu. 

## 📌 Project Overview
Kualitas udara merupakan salah satu aspek lingkungan perkotaan yang dapat dianalisis berdasarkan berbagai parameter pencemar udara. Pada project ini, data ISPU DKI Jakarta tahun 2022 diolah menggunakan Python untuk mengeksplorasi:
- Distribusi kategori kualitas udara
- Distribusi data berdasarkan lokasi pemantauan
- Hubungan antarparameter polutan
- Distribusi konsentrasi polutan pada setiap lokasi
- Perubahan konsentrasi polutan secara temporal

## 📊 Dataset

Project ini menggunakan dataset **ISPU DKI Jakarta Tahun 2022** yang memuat data hasil pemantauan kualitas udara pada beberapa stasiun pemantauan di DKI Jakarta.

Dataset mencakup beberapa parameter utama kualitas udara, yaitu:

- **PM10** — partikulat dengan diameter ≤ 10 µm
- **PM2.5** — partikulat dengan diameter ≤ 2.5 µm
- **SO₂** — sulfur dioksida
- **CO** — karbon monoksida
- **O₃** — ozon
- **NO₂** — nitrogen dioksida

## 🛠️ Tools & Technologies

Project ini dikembangkan menggunakan:
a. Pandas — data processing dan data cleaning
b. NumPy — komputasi numerik
c. Matplotlib — visualisasi data
d. Seaborn — statistical visualization
e. GeoPandas — pengolahan data geospasial
f. Folium — interactive mapping
g. Contextily — basemap visualization
